WebsiteApp – Room Booking System

Project Overview

WebsiteApp is a room booking application developed using ASP.NET Core MVC, C#, and SQL Server.

Technologies Used

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML, CSS, JavaScript
- Bootstrap

Features

- Display available room types.
- Search rooms by check-in and check-out dates.
- Enter guest details and book rooms.
- Calculate booking prices.
- Generate booking confirmation numbers.
- View all bookings.
- Search bookings using confirmation numbers.

Database

SQL Server stores room types, rooms, guest details, and booking information.

How to Run

1. Clone the repository.
2. Open the solution in Visual Studio 2022.
3. Update the database connection string.
4. Apply Entity Framework Core migrations.
5. Run the project.
